01 FOUNDATIONS

WEEK 1 · THE DATA

Data Exploration, Leakage-Free Splitting & Scaling

Start here

Why This Matters

Clinical data is rarely tidy, and careless preprocessing can make a model look better than it is. A clean split and training-only transformations give every later result a more trustworthy foundation.

◎ What you will learn

  • Inspect real-world clinical tabular data and spot patterns worth investigating.
  • Handle missing values safely and understand why preprocessing must not “see” test data.
  • Prepare a fair, reproducible train/test split before fitting transformations.

⌘ Exact learning topics

DataFrame inspection & missing valuesBinary target encodingEDA & correlation heatmapsData leakage preventionStratified 80/20 splitMedian imputation & StandardScaler

↗ Study resources

  • [Video] Corey Schafer: Python Pandas Tutorial (Part 1) - Getting Started with Data Analysis ↗Learn how to load tabular datasets, inspect rows and columns, and set up a clean exploration workflow.
  • [Video] Corey Schafer: Python Pandas Tutorial (Part 9) - Cleaning Data (Casting Datatypes and Handling Missing Values) ↗Spot missing values (NaN / ?), filter invalid entries, and clean columns before modeling.
  • [Video] StatQuest: A Gentle Introduction to Machine Learning ↗Understand why we split data into training and testing sets to judge models on unseen patients.
  • [Video] StatQuest: Data Leakage and How to Avoid It ↗See how fitting scalers or imputers before splitting leaks test-set information and inflates evaluation scores.
  • [Docs] Pandas Getting Started Tutorials ↗Reference DataFrame filtering, summary statistics, and missing-value operations.
  • [Docs] Scikit-Learn Common Pitfalls: Data Leakage ↗Follow the official guidance for isolating training and testing transformations.

02CLASSIFICATION

WEEK 2 · THE PREDICTION

Heart Disease Classification & Clinical Evaluation

Build on Week 1

Why This Matters

A screening model can miss patients who need follow-up even when its overall accuracy looks strong. Reading recall alongside other metrics helps you explain those trade-offs clearly.

◎ What you will learn

  • Train baseline supervised classifiers and compare their predictions fairly.
  • Read a confusion matrix and explain the real-world meaning of its errors.
  • Evaluate screening models with clinical trade-offs in mind, not accuracy alone.

⌘ Exact learning topics

Logistic RegressionRandom Forest ClassifierConfusion matrix (TP, FP, TN, FN)Precision, Recall & F1-scoreStratified K-Fold cross-validationRandom seed reproducibility

↗ Study resources

  • [Video] StatQuest: Logistic Regression ↗Follow how binary probabilities are predicted using the sigmoid curve.
  • [Video] StatQuest: Random Forests Part 1 - Building, Using and Evaluating ↗Learn how an ensemble of decision trees votes to improve tabular classification.
  • [Video] StatQuest: Machine Learning Fundamentals - The Confusion Matrix ↗Identify True Positives, False Positives, True Negatives, and False Negatives.
  • [Video] StatQuest: Machine Learning Fundamentals - Sensitivity and Specificity ↗Understand medical screening trade-offs and why Sensitivity (Recall) is prioritized when catching heart disease.
  • [Video] StatQuest: Machine Learning Fundamentals - Cross Validation ↗See why one train/test split can fluctuate on small datasets and how K-Fold cross-validation stabilizes evaluation.
  • [Docs] Scikit-Learn Classification Metrics & Stratified K-Fold Docs ↗Reference confusion_matrix, precision_recall_fscore_support, and StratifiedKFold.
↗

Weekly build & GitHub submission

Compare two baselines, then explain which errors matter most for screening.

  • Train Logistic Regression and Random Forest on scaled training data; compare test-set confusion matrices, Accuracy, Precision, Recall, and F1.
  • Run 5-fold Stratified Cross-Validation (random_state=42) and reflect on why Recall matters more than raw Accuracy in heart disease detection.

03DISCOVERY

WEEK 3 · THE PATTERNS

Cholesterol Regression & Patient Segmentation

Build on Week 2

Why This Matters

Clinical datasets can answer more than yes-or-no prediction questions. Regression and clustering help you estimate health measures and explore patterns without treating those groups as diagnoses.

◎ What you will learn

  • Predict a continuous clinical value and judge how close predictions are to reality.
  • Use dimensionality reduction to make complex patient data easier to explore.
  • Group similar patients and describe what makes each group distinctive.

⌘ Exact learning topics

Multiple Linear Regression (OLS)MAE, RMSE & R²Feature correlation analysisPCA (95% variance)K-Means clusteringElbow method & Silhouette score

↗ Study resources

  • [Video] StatQuest: Linear Regression, Clearly Explained ↗Build a visual foundation for Ordinary Least Squares and interpreting R-squared.
  • [Video] StatQuest: Multiple Regression, Clearly Explained ↗Extend linear regression to multiple clinical predictors for estimating serum cholesterol.
  • [Video] StatQuest: Principal Component Analysis (PCA), Step-by-Step ↗Understand variance retention and projecting 13 patient attributes into 2D space.
  • [Video] StatQuest: K-Means Clustering ↗See how centroids group similar patients and how cluster quality is evaluated across values of k.
  • [Docs] Scikit-Learn Decomposition (PCA) & Clustering User Guide ↗Reference PCA(n_components=0.95), KMeans, and silhouette_score.
↗

Weekly build & GitHub submission

Explore both a prediction problem and the hidden structure of the data.

  • Predict serum cholesterol (chol) with Multiple Linear Regression; report MAE/RMSE/R² and identify top correlated features.
  • Apply PCA (95% variance), choose cluster k with Elbow + Silhouette methods, visualize clusters in 2D PCA space, and write plain-English profiles for each patient cluster.

04SHIP IT

WEEK 4 · THE APPLICATION

Consolidation, FastAPI Backend & Interactive Dashboard

Final week

Why This Matters

A notebook documents an experiment, while a pipeline-backed app shows how it can be used repeatedly. Packaging, validation, and clear documentation help make results reproducible and usable.

◎ What you will learn

  • Refactor notebook experiments into clean, reusable Python scripts.
  • Bundle preprocessing and the model so new inputs get the same transformations.
  • Serve predictions through an API and make them accessible in an interactive web UI.

⌘ Exact learning topics

Scikit-Learn PipelinesModel serialization (joblib)REST APIs with FastAPIInput validation with PydanticInteractive UI with StreamlitProduction repo organization

↗ Study resources

  • [Video] Data School: How to Build a Scikit-Learn Pipeline ↗Bundle SimpleImputer, StandardScaler, and a classifier into one leak-free pipeline object.
  • [Video] CampusX: FastAPI for Machine Learning Models ↗Load a serialized .joblib model into FastAPI and validate inputs with Pydantic.
  • [Video] Data Professor: How to Build a Machine Learning Web App in Python with Streamlit ↗Turn sliders and dropdown inputs into an interactive prediction dashboard.
  • [Docs] Scikit-Learn Pipelines & Model Persistence Docs ↗Reference Pipeline composition and saving or loading models safely with joblib.
  • [Docs] FastAPI Official Tutorial: First Steps & Request Body ↗Define GET and POST endpoints and test them through interactive Swagger /docs.
↗
